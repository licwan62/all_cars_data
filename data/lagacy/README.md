# 07 版旧尺码独立分析

本分析用三个店铺的 07 版库存尺码按半周长差值匹配尺寸库，并发布到
`source/lagacy/source-0903`。

默认输入：

- `07-车衣数据.csv`：型号与侧片长；侧片长单位为厘米。
- `source/all-07.csv`
- `source/hnt-07.csv`
- `source/tm-07.csv`
- `source-0903/尺寸库.csv`
- `source-0903/参数.csv`

运行：

```powershell
python source\lagacy\analyze_legacy_sizes.py
```

计算与匹配口径：

```text
尺寸库记录半周长_mm = (L-IN + H-IN) × 25.4
车衣半周长_mm = 侧片长_cm × 10 + 1500
半周长差值_mm = 车衣半周长_mm - 尺寸库记录半周长_mm
```

差值必须严格大于 `参数.csv` 的 `半周长余量下限`，并严格小于
`半周长余量上限`，才进入同分类候选池。池内按 `档位序号` 升序、原规则
行号升序取首条。本次口径不使用 CAB 作为筛选条件。

`3XL+0 → 3XL+-0` 为明确别名；其他内部尺码仅在精确型号缺少时尝试去掉
末尾 `-0`。缺少可用侧片长的尺码保留在发布规则表中，但不参与匹配。

发布目录包含：

- 增加半周长字段后的 `all-07.csv`、`hnt-07.csv`、`tm-07.csv`
- 三份 `*-尺码匹配分析.csv`
- 三份 `*-未匹配.csv`
- 三份 `*-规则使用统计.csv`
- `校验报告.json` 与 `分析报告.md`
