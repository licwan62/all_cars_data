## 日常入口

在 `D:\Home\Repo\all_cars_data` 执行：

```powershell
python scripts/website.py build     # 本地构建并验收
python scripts/website.py publish   # 发布已校验候选到 NAS + ECS
python scripts/website.py release   # 构建并发布 NAS + ECS
python scripts/website.py ecs-only  # NAS 已成功后，仅重试 ECS
```

候选使用当前发布 JSON；上游、源码或规则变化后需重新构建。发布方继续使用 `pipeline_carstable_to_webapp` 以保持 NAS 文件归属及 ECS 历史兼容。部署配置位于节点 `data/pipeline.yaml`；Workbench 认证保留在本机配置，不复制密钥。

本次完成迁移、构建与本地发布演练，**未改写实际 NAS 或 ECS 线上站点**。线上发布仍由上述明确命令触发。
