# XV70欧洲Hybrid可见版本适用复核

**结论：P2-011／source_b/round5-02 保持hold，不能据当前证据覆盖 `RU-ebfa236c9b0c4ba1 / Toyota Camry Sedan 2017-2021 RU`。**

实际看过输入，车头Toyota徽有蓝色边缘，前翼子板有明确HYBRID字样。它与普通XV70共享灯杠/车身造型，仍有可见版本差异。

- [Toyota Europe 2019-04-15厂家稿](https://newsroom.toyota.eu/2019-the-new-toyota-camry/)明确欧洲推出的是2.5 Hybrid Dynamic Force／THS II混动版本。
- [Drom俄罗斯XV70目录](https://www.drom.ru/catalog/toyota/camry/g_2017_7683/)明确俄版使用6AR-FSE 2.0、2AR-FE 2.5、2GR-FKS 3.5三类汽油发动机，对应ASV71/ASV70/GSV70及列明汽油配置；该目标目录未提供Hybrid承接证据。
- 冻结来源映射为`RU|toyota/camry|VIII (XV70)|2017-2021|Sedan|-|-`，没有直接证据证明空版本字段授权所有跨市场可见版本都共图。

因此，相同代际前脸以及“不宣称俄原装”的限制性声明，均不足以补齐这个Hybrid可见版本的适用关系。这不是认定所有generic Sedan永远排斥Hybrid，而是此项证据不足。不得通过去除Hybrid翼徽、改蓝车标来伪造俄燃油配置。

解除条件：换同代同改款、已核目标市场普通可见版本来源；或提供明确允许此Hybrid版本承接冻结条目的直接映射依据。下载、解码、许可及源OSS fullGET事实仍保留，但不算该配置身份闭环，也不批准成品。详细SHA及来源见`xv70-applicability-hold.json`。未修改正式台账/Git。
