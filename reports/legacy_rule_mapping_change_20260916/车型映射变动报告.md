# `data/lagacy` 与 `public` 当前发布版车型尺码映射变动报告

## 结论

- 旧表与现行表各 **4,354** 条；标准化车型键全量一对一对齐。
- 其中 **2,122** 条最终尺码发生变化，记录变动率 **48.7%**，涉及销量 **330,817,648**。
- 从不可用转为可匹配 **64** 条；从可匹配转为不可用 **50** 条；可用尺码之间迁移 **1,969** 条；不可用状态之间变化 **39** 条。
- 两份 `DIMENSION-ID` 的文本格式完全不同，不再直接用它连接；改用 `MAKE + MODEL + 版本 + 结构 + YEAR + CAB + BED` 清洗后的业务键。
