# 尺码匹配规则说明

这是 [`尺码匹配规则.csv`](../尺码匹配规则.csv) 的人读版。CSV 保留为与已发布 `全量数据.csv` 对应的机器规则快照；本页删除未使用的“版本”列，并将完全相同的跑车、三厢车规则合并展示，便于维护和核对。

## 规则怎么匹配

先按车型白名单匹配定制规则；其他车型按车辆分类依次检查通用规则。车辆同时满足以下条件时可使用该尺码：

- `L-MM ≤ 长上限`
- `插片指数 ≤ 插片指数上限`

满足条件的候选还须满足长度余量（`长上限 − L-MM`）不超过 **550 mm**。`999` 表示该规则不限制插片指数。

## 车型插片指数计算公式

`R` 表示按项目规则四舍五入到整数，单位均为 mm。

| 车型分类 | 插片指数 |
| --- | --- |
| 非皮卡（两厢车、跑车、三厢车、越野车等） | `R((前宽-MM + 后宽-MM) / 4 − 750)` |
| 皮卡 | `R(前宽-MM / 2 − 750)` |

皮卡只采用前宽，避免后轮毂外凸导致插片需求被高估；负值按实际结果保留，不截断为 0。

## 维护约定

修改实际匹配边界、尺码或白名单时，先更新 CSV 并重新发布对应的 `全量数据.csv` 与 `尺码匹配报告.json`；随后同步本说明页。仅调整本页的分组合并与说明文字，不会改变实际匹配结果。
