# W 型车 SKU 聚类

本目录发布 `public/全量数据.csv` 中以下逻辑尺码的消费者车型聚类：

- `3L-W`
- `3XL-W`
- `3XXL-W`
- `3XXXL`
- `3XXXXL`

`3XXXL` 和 `3XXXXL` 分别由内部尺码 `3XXXL-0`、`3XXXXL-0` 映射得到。

## 文件

- `car_cluster_summary.csv`：聚类主表，每行一个消费者车型簇，`CLUSTER_ID` 唯一。
- `car_cluster_detail.csv`：源记录明细及其 `CLUSTER_ID`、逻辑尺码。
- `car_cluster_atom_audit.csv`：原子事实的 Cluster 和逻辑尺码唯一性审计。

合计 80 个聚类、725 条源记录和 1,454 个唯一原子事实。

## 聚类与校验口径

- 聚类主键为 `逻辑尺码 + MAKE + MODEL`。
- 车身结构、版本、TRIM、代际和年份保留为簇内适配信息。
- 原子事实为 `MAKE + MODEL + TRIM + 版本 + 结构 + YEAR`。
- 年份区间和逗号分隔的 TRIM 展开后执行全局唯一性检查。
- 本批次跨逻辑尺码原子冲突为 0，多 Cluster 原子重叠为 0，年份解析异常为 0。
- 本批次不生成源数据中不存在的年份、TRIM、版本或结构组合。

候选生成与复算脚本保存在 `聚类SKU/changes/W型车/`。
