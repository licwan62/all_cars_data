# W 型车发布数据

本目录仅发布最终审核通过的链接级发货适配数据。

当前发布批次为 `0915.1-tolerance-550`，基于 2026-09-15 发布的
`public/全量数据.csv` 与 `public/尺码匹配规则.csv`。聚类范围使用新规则的
`4L`、`4XL`、`4XXL`、`4XXXL`、`4XXXXL` 以及三种专用尺码。

## 发布文件

- `链接发货适配表.csv`：以 `链接名称` 为唯一主键，包含外键 `CLUSTER_ID`、`SKU_NAME`、尺码、预计销量、销量占比、发货数量、适配车型（Make + Model）与年份，以及长宽高的最小值、最大值和尺寸集中度。
- `尺码发货汇总.csv`：聚类合并和发货分配全部完成后，按最终发货尺码汇总的聚类数量、预计销量和发货数量。

## 发货规则

- 总发货量为 801。
- 当前共有 151 个最终 Cluster，其中 93 个链接获得发货量并进入发布适配表。
- 每个链接的发货数量均为 3 的倍数。
- `尺寸集中度` 为 0–100 分，越高表示长宽高数据越集中。算法使用长宽高的总体变异系数加权，权重分别为 60%、25%、15%，再按 `100 × exp(-10 × 加权变异系数)` 换算。
- `SKU_NAME` 格式为 `品牌缩写_车型缩写_Y起始年-结束年_尺码`；年份使用真实原子年份的起止边界，不嵌入分段年份。链接名称使用同一边界年份以便检索；`适配年份` 则保留原子明细实际存在的分段范围。
