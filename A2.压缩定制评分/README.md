# A2.压缩定制评分

把 `A1.全量生成/output/全量表_汇总.csv` 压缩为按匹配尺码分池的结构/年份区间表，
并结合三张人工维护台账给出定制需求度评分。详见 [AGENTS.md](AGENTS.md)。

## 输出

- `output/压缩尺码表.csv`：区域、MAKE、MODEL、结构池、年份区间、自动尺码、变体数、覆盖原子数。
- `output/定制需求度评分.csv`：品牌、车型、结构、三个维度分项评分、综合定制需求度、
  定制需求等级（低/中/高/数据不足）、参与评分维度数。

## 压缩算法概要

1. 把每行的 `YEAR` 区间展开为逐年原子事实 `(区域,MAKE,MODEL,结构+CAB+BED,年份,自动尺码)`。
2. 同一变体同一年份多个候选尺码时按多数票取值，少数派写入批次 `冲突报告.json`。
3. 同一年份内，把自动尺码相同的变体合并为一个结构池。
4. 结构池组合在相邻年份完全相同时合并为一个年份区间；不连续的年份不跨越合并。

## 评分算法概要

三个维度（差评、人工维护进度、车耳状态）各自归一到 0~1，按 `data/定制评分规则.json`
里的权重加权平均；缺失的维度不参与、权重在剩余维度间重新归一；三个维度都没有记录时
输出"数据不足"而不是 0（不能把"没人录入"当成"不需要定制"）。

打分键（品牌+车型+结构）按 `data/结构归并映射.json` 做跨区域结构归并（例如美区的
`SUV` 与欧俄的 `SUV 5dr` 是同一种车身，归并为一个键），避免同一台车因为区域标注
习惯不同而在评分表里重复出现。
