# 等效长尺码匹配测试副本

这是 `尺码计算` 的隔离测试入口。它只读取现行 `source`、现行尺码规则和
`source/车衣数据/07-车衣数据.csv`，输出仅写入本目录，不覆盖
`尺码计算/output` 或 `source/全量数据.csv`，也不调用发布命令。

测试口径：

- `等效长 = (L-MM + W-MM) × 周长系数 - 750`
- 尺码的 `等效长上限 = 07-车衣数据.侧片长 × 10`（厘米转毫米）
- `等效长 <= 等效长上限`
- 同时使用新的 `插片指数上限`
- 原规则的分类、CAB、版本、`档位序号`、启用状态和池回退逻辑均保留
- 07 表中侧片长为空或为 `—` 的尺码保留在规则副本中，但不参与匹配

运行：

```powershell
python 尺码计算\半周长测试\half_perimeter_analysis.py
```

输出：

- `output/半周长测试结果.csv`
- `rules/半周长匹配规则.csv`

结果仅供测试，不发布。
