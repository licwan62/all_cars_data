# 双层 W 尺码发布

发布日期：2026-09-11

本批次新增高插片小尺码 `3L-W`，并恢复 `3XL-W` 的保守上限。

- 将跑车、三厢车的 `3L` 插片指数上限由 999 调整为 120。
- 新增 `3L-W`：4737–4850 mm，高插片车型。
- `3XL-W` 调整为 4851–5050 mm；`3XXL-W` 自 5051 mm 起承接。
- 67 条车型发生尺码调整，涉及销量 12,380,765；另有 73 条车型仅更新长度余量。
- 1957 Mercury Cougar Coupe 和 1969–1970 Mercury Cougar Convertible（均为 4826 mm）调整为 `3L-W`，长度余量 24 mm。
- 总记录、已匹配、无可用尺码、数据不全及总销量均未变化。
