# 0910.2 增加 3XXL 兼容规则计算

使用规则：`尺码计算/rules/尺码匹配规则-0910.2-增加3XXL兼容.csv`  
输入：当前 `public` 尺寸库、销量明细、车身分类和全量表 TRIM。  
输出：`pandas_output.csv`。本批次未发布。

## 结果

| 项目 | 新规则 | 当前发布版 | 变化 |
| --- | ---: | ---: | ---: |
| 总记录 | 4,354 | 4,354 | 0 |
| 已匹配 | 3,541 | 4,046 | -505 |
| 无可用尺码 | 740 | 235 | +505 |
| 数据不全 | 73 | 73 | 0 |
| 销量合计 | 749,626,457 | 749,626,457 | 0 |

共有 602 条记录的自动尺码发生变化，涉及累计销量 73,672,675。其中 505 条从已匹配转为无可用尺码。

## 主要原因

新规则把跑车和三厢车的 `3XL`、`3XL+`、`3XXL`、`3XXXL` 插片指数上限从 999 收紧为 150，因此新增大量“插片指数超上限”：495 条，累计销量 63,641,048。其余未匹配中，超余量 70 条、超长 52 条、未记录原因 123 条。

## 发布前注意

三厢车的 `3XXXXL` 规则当前写成内部尺码 `3XXXXL-0`，与跑车共用 `-0` 输出。这使 86 条原 `3XXXL/3XXXL-0` 记录转为 `3XXXXL-0`，其中包含三厢车。如果三厢车预期输出不带 `-0`，应先把三厢车规则的内部尺码改为 `3XXXXL` 再计算。

另外，“3XXL 兼容”目前并未提高整体覆盖：匹配量反而减少 505 条。若目标是让高插片指数的 SD2 继续使用 `3XXL–3XXXXL`，则 150 的插片上限会排除多数 SD2，需要确认这是刻意限制还是规则填写错误。
