# W 型车链接分析

本项目只处理 `D1.聚类SKU/artifacts/W型车`，与皮卡项目的输入、合并测试和输出目录完全分开。

```powershell
python run.py
```

## 输出结构

`artifacts/<版本>/` 保留该版本的发布候选表和必要的分析、上架与校验明细：

- `01_发货方案/`：`尺码发货汇总.csv` 与 `发货方案报告.md`。
- `02_聚类数据/`：`聚类主表.csv` 合并聚类档案、上架命名、发货分配、取整依据和尺寸范围；原子明细、ID 映射及关联链接按各自粒度单独保留。
- `04_校验报告/`：年份与聚类合并校验数据。
- `00_输入/`：原始尺码级发货输入。
- `05_输出/`：可直接发布的 `链接发货适配表.csv`，以及在流程末端按最终发货尺码汇总的 `尺码发货汇总.csv`。

原始引擎导出的聚类主表会被字段解耦后的最终主表替代；旧的 `最终报告.md` 因采用旧分配口径而不再保留。

发货数量按每个 Cluster 的预计销量占比计算；默认总供给为 801，以 3 件为最小发货单位并使用最大余数法分配，因此每笔发货量及汇总总数均为 3 的倍数。

流程依次重建 W 型车聚类候选、执行年份/尺码合并门禁，然后生成本项目的版本化 `artifacts/0914/`。

`artifacts/0914.2-make聚合/` 使用 `D1.聚类SKU/artifacts/W型车/0914.2-make聚合/` 的 `逻辑尺码 + MAKE` 聚类实验重新计算链接与发货；该版本不覆盖 public 正式发布表。
