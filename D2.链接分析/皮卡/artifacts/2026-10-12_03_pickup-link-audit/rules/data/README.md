# 皮卡链接分析规则

- `链接字段规则.json`：用户展示字段规则。`适配车型` 只保留品牌与车型，年份单独写入 `适配年份`。
- `PHYSICAL_SKU映射.json`：皮卡既成发货尺码到当前通用尺码的发布映射，来源为 `A0.尺码计算/data/参考/新旧尺码对应/新旧尺码对应2.csv` 的皮卡记录。
- `发货事实.csv`：人工确认的 SKU 粒度发货事实；`SKU_NAME` 唯一，发货数量不依赖 Cluster。
- `SKU上架映射.csv`：确认 SKU 与工作簿上架记录的一对一映射，用于补充带 CAB/BED 的适配车型和适配年份。
- 车型与上架字段仍从 `../data/发货单明细.xlsx` 读取；发货数量只认本目录的 `发货事实.csv`。
