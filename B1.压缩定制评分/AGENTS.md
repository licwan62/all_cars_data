# 压缩定制评分 Agent（定制需求度评分）

`id: compression-scoring`。结合上游差评数据，为每个 品牌+车型 打出
"定制需求度（通用版型偏离度）"评分：

- **差评评分**：来自上游 `B0.差评分析/output/差评分析表.csv`（品牌+车型+结构 粒度），
  按各结构的"差评数量"加权平均合并成 品牌+车型 一行。
- **差评备注**：把各结构"主要差评原因"里属于尺寸/耳位问题的条目拼起来（质量差、拉链、
  绑带、收纳袋等和车身尺寸/耳位无关的问题不统计）；只有一个结构时不加结构前缀，多个结构
  才逐条打结构前缀；皮卡车型另外拼入上游驾驶室/货斗信息。
- **耳位(普通/靠前/靠后)**：来自上游 `B0.差评分析/output/耳位分析表.csv`，按 品牌+车型
  直接透传，不参与评分（详见下方"迁移记录"）。
- **尺码**：来自上游 `差评分析表.csv` 各结构行的"尺码"列，按 品牌+车型 合并（按"；"拆分、
  去重、保持首次出现顺序），直接透传，不参与评分。
- **年份**：从差评分析表.csv 各结构行的"年份"列合并去重，压缩成 `95-97/26` 这种两位数
  年份+连续区间的格式；没有年份记录时留空（代表"未知或具有普遍性"）。

上游：`A1.全量生成/output/全量表_汇总.csv`（用于推导评分键 品牌+车型）、
`B0.差评分析/output/差评分析表.csv`（差评维度输入、年份）、
`B0.差评分析/output/耳位分析表.csv`（耳位透传字段）、
`B0.差评分析/output/皮卡驾驶室货斗分析表.csv`（皮卡驾驶室/货斗透传字段）。

本节点不再做压缩（结构池 × 年份区间）——该机制已迁移到 `A2.压缩尺寸信息`，产出
`压缩尺码表.csv`；两者的"结构"粒度不同，因此评分键仍直接从全量表推导，不依赖 `A2` 的输出。

## 目录

- `data/定制评分规则.json`："差评"维度的字段口径、"差评备注"的尺寸/耳位关键词与排除前缀、
  评分档位阈值。调整规则改这个文件即可，不用改代码。
- `src/scoring.py`：合并差评表打分算法。
- `src/run.py`：编排入口，创建 `artifacts/<批次>/` 快照并校验通过后原子更新 `output/`。

```powershell
python src/run.py
```

## 已知限制 / 待办

- 评分只有"差评"一个维度，覆盖不到差评原始数据之外的其它定制信号；后续如需要新增维度，
  参考 `src/scoring.py` 里已删除的 `score_manual_progress`/`score_ear_status`（见 git 历史）
  重新接入，但要吸取教训：人工登记表长期覆盖率太低，新增维度前先确认有稳定的数据来源。
- 评分权重/分档阈值是初版，后续按实际使用效果调整 `data/定制评分规则.json`。
