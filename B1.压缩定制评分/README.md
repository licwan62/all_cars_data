# B1.压缩定制评分

结合上游 `B0.差评分析` 的差评分析表、耳位分析表和皮卡驾驶室货斗分析表，为每个 品牌+车型
打出"定制需求度（通用版型偏离度）"评分。详见 [AGENTS.md](AGENTS.md)。

压缩年份/结构池（`压缩尺码表.csv`）已迁移到 [A2.压缩尺寸信息](../A2.压缩尺寸信息)，
本节点不再产出该表。

## 输出

- `output/定制需求度评分.csv`：品牌、车型、差评评分、定制需求等级（低/中/高，数据不足时
  留空）、差评备注（只保留尺寸/耳位相关的差评原因，如 `sedan 尺寸不合适(8)；coupe 后视镜
  位置不对(1)`；单一结构时不加结构前缀；皮卡车型末尾拼入驾驶室/货斗信息，如
  `Crew Cab/Short Bed(14)`）、耳位(普通/靠前/靠后)（上游透传，不参与评分）、年份（差评
  涉及年款，压缩成 `95-97/26` 格式，留空代表未知或具有普遍性）。

## 评分算法概要

评分只有"差评"一个维度，按 `data/定制评分规则.json` 里的口径把 差评占比（或严重度评级）
归一到 0~1；没有差评记录时"差评评分"和"定制需求等级"都留空（不能把"没有差评数据"当成
"不需要定制"，也不写字面的"数据不足"占位文本）。

打分键是 品牌+车型（不再含结构）：上游 `差评分析表.csv` 里同一 品牌+车型 下不同结构的行，
按各自"差评数量"加权平均合并成一个评分；结构层面和尺寸/耳位相关的差评原因保留在
`差评备注` 里，质量差、拉链问题等无关原因按规则过滤掉。
