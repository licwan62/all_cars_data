# Toyota Prius 家族定制 SKU 分析与 Sketchfab 参考任务

## 结论与范围

区域：US；车系范围：Toyota Prius / Prius C / Prius V / Prius Prime / Prius Plug-in Hybrid；结构：Hatchback / Wagon。
13 条尺寸记录形成 2 个尺寸候选 SKU。跨代际共版须完成外形核验和实车打样。

分析范围扩大为 Prius、Prius C、Prius v、Prius Prime 与 Prius Plug-in Hybrid；保留 Hatchback 与 Wagon，明确排除 2001–2003 Prius Sedan。
SKU 包络的 L/W/H 最大跨度统一放宽至 300 mm。该阈值只用于尺寸候选聚簇，不能证明不同车身轮廓、镜耳、尾门或裁片可直接共版。
家族记录按统一尺寸阈值形成候选 SKU；跨 MODEL 的候选使用 TOYOTA-PRIUS 家族标识，不冒充任何单一子车系的标准 DIMENSION-CODE。
现有差评仅命中 Prius Hatchback：尺寸不合适 2 次、太重与不好穿各 1 次。其他子车系没有直接差评记录，不应被解读为已经验证适配。
优先对 Prius C（短车）、Prius v（高车）及最长 Prius/Prime 的极值车做实车打样；如果车顶弧线、镜耳或尾部收束不能通过放量解决，应拆分 SKU。

## 打样验收与待确认事项

1. 每个拟共版 SKU 验证 L/W/H 极值车型，拍摄前、侧、后与镜耳位置；记录偏大、偏小、偏长、偏短及下摆覆盖。
2. 核对车顶弧线、尾门、扰流板和镜耳位置；跨代际外形差异无法通过放量解决时拆分 SKU。
3. 记录样品重量、安装用时及前后方向辨识；镜耳位置通过实车测量确认，不依据缺失的耳位反馈指定靠前或靠后。
4. 补充购买年款、实际尺码、偏差部位与照片，并回填差评人工台账。

先测 2012–2015 与 2004–2009 的覆盖差异，再测 2016–2022 和 2023–2026 的长度/宽度极值；订单年款确认、镜耳定位和尾部收束纳入验收。
太重和不好穿各只有一次原因记录：记录样品克重、单人安装用时与方向辨识，验证后再决定轻量化或工艺变更。未确认偏差方向前不直接整体加长或缩短。
