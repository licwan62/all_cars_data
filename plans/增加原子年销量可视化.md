# Web 增加原子年销量可视化

## 目标与口径

在现有“车型尺寸演变”弹窗中增加**年度预估销量分组柱状图**，按配置展示，与尺寸图、SIZE 时间带共用年份轴、筛选和图例。

- 最小粒度为 `DIMENSION-ID + ATOM_YEAR`，直接读取上游原子销量，不将年份段销量均摊到每年。
- US、HNT、TM、TM_拆分共用美国车型预估销量；店铺视图明确标注“美国车型预估销量”，避免理解为店铺订单量。
- EU、RU 提示“暂无同口径年度销量数据”。
- 已核对当前数据：15,223 条年度原子覆盖 4,383 条 US 尺寸记录，逐 ID 汇总与 A0 一致；2027 年两条缺失保留为空。

## 实施内容

### 1. 接入正式数据与构建流程

- 在网站流水线配置增加 `sales_output_dir`，指向 `all_cars_data/nodes/02.销量评估/output`。
- 同时修正当前 A0、A1 配置仍指向迁移前目录的问题，统一使用 `nodes/` 下正式发布目录。
- 将销量节点纳入现有上游固定机制：构建开始时固定输入、校验 manifest 与 SHA256，恢复运行时复核固定副本。
- 核对 A0 manifest 登记的原子销量文件 SHA256 与本次销量输入一致；不一致则停止构建，提示更新上游。
- 校验原子身份唯一、年份位于尺寸记录范围内、销量非负，以及年度已知值汇总与 A0“尺寸组销量”守恒。

### 2. 新增销量数据接口

- 发布独立清单 `sales-year-data.json`，按类别、MAKE 分片；US 和各店铺复用同一份数据。
- 每个 DIMENSION-ID 存储有序的 `[年份, 预估销量]`，缺失值使用 `null`；清单记录销量版本、A0 版本及输入 SHA256。
- 扩展现有可视化加载接口，增加 `loadModelSales(modelKeys)`；打开弹窗时仅加载所选车型涉及的分片，并缓存加载结果。
- 保持现有尺码配对数据格式不变，销量独立加载；失败时在销量面板提供重试，尺寸图继续可用。

### 3. 增加年度销量面板

- 源码维护在 `site_overrides`，复用现有 ECharts，在长度图下方增加默认展开的“年度预估销量”面板及收起按钮。
- 每个可见配置对应一组年度柱，颜色与现有图例一致；不同配置并排展示，纵轴从 0 开始，单位为“辆”。
- 同配置同年涉及多条尺寸记录时，按唯一原子 ID 去重后求和；不同配置分别展示，不重复计入同一原子。
- 跟随现有“完整车型历史／仅当前筛选”、配置选择和年份窗口；各面板统一缩放、年份指示和点击锁定。
- 悬浮详情显示年份、配置销量、可见配置当年合计、原子 ID 和来源版本。合计存在缺失时标注“已知销量小计＋缺失数”。
- 缺失不补零，真实零值显示为 0；增加可展开的年度文字明细。尺寸单位切换不改变销量。
- 更新资源版本号和站点校验，确保重新构建后功能仍保留。

## 验收与测试

- **数据测试：**覆盖正常年份、零值、缺失、重复原子、非法年份、孤立 ID、负值、汇总不守恒及来源 SHA256 不一致。
- **计算测试：**验证配置年度求和、原子去重、部分缺失提示，以及 US 与店铺视图的销量一致。
- **浏览器验收：**覆盖单车型、多配置、多车型、皮卡 CAB/BED、图例开关、范围切换、年份缩放、全屏及加载失败重试。
- **回归检查：**现有检索、压缩表／全量表切换、复制、规则叠加、SIZE 时间带及定位原记录功能通过。
- 运行 Python 测试、现有 Node 数据测试和浏览器验收；构建校验失败时保持当前站点不变。

## 交付与默认边界

- 交付源码、生成数据、测试结果及桌面／窄屏截图。
