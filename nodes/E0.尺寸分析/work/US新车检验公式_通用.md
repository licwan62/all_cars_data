# US 新车两级检验公式（通用尺码 × 通用车身号）

## 使用表

- 将 `US新车尺码警戒_通用.csv` 导入 Excel，表名设为 `tb_尺码警戒`。
- 将 `US新车打版上限_通用.csv` 导入 Excel，表名设为 `tb_打版上限`。
- 新车输入表至少包含：`计算尺码`、`通用车身号`、`车长-MM`、`车宽-MM`、`车高-MM`。
- `计算尺码`只使用 US 0924 表中 `方案=通用` 的尺码；`通用车身号`只使用 03 标准中的 17 个车身号。

## 一级：宽高经验警戒

```excel
=LET(
  s,[@计算尺码],
  w,[@[车宽-MM]],
  h,[@[车高-MM]],
  wLo,XLOOKUP(s,tb_尺码警戒[自动尺码],tb_尺码警戒[宽警戒下限-MM],NA()),
  wHi,XLOOKUP(s,tb_尺码警戒[自动尺码],tb_尺码警戒[宽警戒上限-MM],NA()),
  hLo,XLOOKUP(s,tb_尺码警戒[自动尺码],tb_尺码警戒[高警戒下限-MM],NA()),
  hHi,XLOOKUP(s,tb_尺码警戒[自动尺码],tb_尺码警戒[高警戒上限-MM],NA()),
  IF(OR(w<wLo,w>wHi,h<hLo,h>hHi),"警戒","正常")
)
```

## 动态允许最大车宽

```excel
=LET(
  key,[@计算尺码]&"|"&[@通用车身号],
  lim,XLOOKUP(key,tb_打版上限[校验键],tb_打版上限[长度组合警戒上限-MM],NA()),
  lim-[@[车长-MM]]
)
```

实际车宽大于该结果时，长度余量会小于 100 mm。

## 二级：长度风险

```excel
=LET(
  key,[@计算尺码]&"|"&[@通用车身号],
  lim,XLOOKUP(key,tb_打版上限[校验键],tb_打版上限[长度组合警戒上限-MM],NA()),
  IF([@[车长-MM]]+[@[车宽-MM]]>lim,"可能不够长","正常")
)
```

## 动态允许最大车高

```excel
=LET(
  key,[@计算尺码]&"|"&[@通用车身号],
  lim,XLOOKUP(key,tb_打版上限[校验键],tb_打版上限[弧高组合警戒上限-MM],NA()),
  lim-[@[车宽-MM]]/2
)
```

实际车高大于该结果时，侧余高率会小于 -0.15。

## 二级：高度风险

```excel
=LET(
  key,[@计算尺码]&"|"&[@通用车身号],
  lim,XLOOKUP(key,tb_打版上限[校验键],tb_打版上限[弧高组合警戒上限-MM],NA()),
  IF([@[车高-MM]]+[@[车宽-MM]]/2>lim,"可能不够高","正常")
)
```

## 两级综合结论

假设前述结果列名为 `一级尺寸警戒`、`长度风险`、`高度风险`：

```excel
=LET(
  level1,[@一级尺寸警戒]="警戒",
  level2,OR([@长度风险]="可能不够长",[@高度风险]="可能不够高"),
  IFS(
    AND(level1,level2),"高风险：尺寸越界且打版不足",
    AND(NOT(level1),level2),"打版风险：尺寸常见但余量不足",
    AND(level1,NOT(level2)),"复核：尺寸越界但打版余量正常",
    TRUE,"正常"
  )
)
```

二级公式必须对每辆新车执行，不能只对一级警戒车型执行；否则会漏掉尺寸常见但打版余量不足的车型。
