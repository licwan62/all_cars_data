# 美国组合车型维护

model_members.json只登记名称成员关系。registered不代表成员年份、尺寸或车罩适配已核定；别名也不能使整段组合年份变为独立覆盖。C/K暂不拆词。所有新增组合须显式登记，不按斜杠、前缀或尺寸相同自动合并。

audi_a7_split.json当前为pending。两条组合行整组保留，现有2026 RS7身份不变。候选逐成员逐年列出2012–2025范围，空尺寸是待核，不允许复制组合尺寸。本地参考库缺行不证明美国未销售。

整组替换需将每个成员每个年份标为present或absent，并提供美国市场供售证据；供售年份必须全部有独立尺寸段，连续年份才能合段，尺寸变化必须分段。证据中的dimension_records逐成员、逐年保存英寸数值、unit=in及width_basis=without_mirrors，数值必须与目标段完全相符；只有verified状态可进入正式库。证据目录中的partial、lead和旧站访问限制不得自行当作verified。

供售证据的presence_records必须逐成员、逐年明确presence=present/absent，不能用“该车型存在”的泛泛说明证明停供。尺寸证据同时记录generation并与原段代际核对。

approved还要求结构审核、车形、编码、销量和尺码计算的下游审查记录。编码旧值必须preserve；销量只接受member_evidence或unallocated，绝不能把整个组合销量复制给每个成员。审查标记不替代实际运行验证；任何实际身份变更必须先在沙箱中完成全活跃下游重建、编码维护、身份核对及销量总量核对，成功后才按拓扑发布。

US_ID迁移.csv只包含已生效映射，当前只有表头。消费方不得把一对多映射当字典取首条或复制全部事实，必须按成员、年份和证据分配；未分配销量保留汇总待核。候选与待核接口不列入public_outputs。

规则、证据、测试需一起修改，再执行正式RunBatch入口。失败不更新output。历史来源及原始00导入不回写，拆分前原记录指纹不符时必须停止并重审。
