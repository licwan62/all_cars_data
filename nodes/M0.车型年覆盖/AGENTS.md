# M0 车型年覆盖

本节点负责两份原始参考资料的维护、全部出现名称与年份的名录、01/02覆盖率和人工回补候选。原始CSV位于data/data_source，不再由01维护。

正式运行：仓库根 `python scripts/run_nodes.py --nodes model-year-coverage`；节点目录登记入口 `python src/run.py`。原生读取集中JSON，通过RunBatch发布到json/model-year-coverage，根节点HTML由统一构建器使用src/report.html生成并归档。

data仅人工维护。来源登记、统计范围、品牌映射、名称映射、人工裁决使用CSV。名称映射须approved及依据，并明确alias或family层级；人工裁决action为exclude、confirm_market或confirm_model_absent且须依据。上游01发布的名称成员规则优先复用，不访问上游data。

只使用明确年份；无年份车型保留名录，不制造年份。保留车型类别、来源、原始名称和CSV逻辑记录号。车型级国家不能证明逐年供售；trimslate的confirmed也不是本项目核实。名称只自动规范大小写、Unicode和空白，标点和斜杠不擅自合并。组合覆盖不能计入独立覆盖。

参考分母不包含仅从01/02观察的车型年，避免用库本身补大分母来抬高覆盖率。评估年后和人工排除单列。市场已核分母为空显示无样本，不显示100%。Make/Model覆盖只表示存在独立记录，不表示车型年或配置完整。

映射只改变比较，不合并原始参考身份或分母。独立记录覆盖与车系级覆盖分别计数；已有直接独立记录不得因车系映射被降级。名称未匹配不等于车型缺失；年份缺口仅为名称已对应后的库内年份差集。新增名称未匹配、已对应缺口、映射影响、名称映射审计四份JSON，HTML分别展示并支持筛选导出。名称未匹配任务先在M0处理，不自动交00/01。

本节点不得写入00/01的data，不执行回补、不启动上游命令，不发布NAS。回补候选ID稳定；人工在目标节点登记证据并正常运行后，本节点再次读取当前JSON核对。历史artifact与原始证据不可反向改写。
