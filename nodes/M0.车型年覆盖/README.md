# 车型年全集与覆盖率

「US 已覆盖车型」可直接筛选和导出，集中接口为 `json/model-year-coverage/US已覆盖车型.json`。每行一个具有独立记录的参考车型，附实际独立覆盖的参考年份。

直接打开本目录 `车型年全集与覆盖率.html`，按区域、品牌、原名或标准车型名、年份、来源和状态筛选，导出当前结果CSV。图表区分映射前独立覆盖、映射后独立覆盖、车系级覆盖、名称未匹配和已对应年份缺口。状态筛选只影响表格，不缩小指标分母。

两份原始CSV完整接收于data/data_source。trimslate提供明确车型年，vehicles提供无年份的车型/类别/市场线索；既有01/02出现的其他车型年也进入全集，标为仅库内观察，不进入参考覆盖分母。

每条来源记录使用来源ID、文件SHA和逻辑记录号追溯；原始名称和年份保存。国家/区域线索可能仅适用于车型，并非各车型年。别名须显式映射；无法对应的记录保留在待核分母中。

名称规则维护在 `data/品牌映射.csv` 和 `data/名称映射.csv`，口径与依据见 `data/名称映射说明.md`。alias 为书写别名，family 为车系归属，后者不证明具体配置或尺寸一致。映射保留原参考身份与分母。HTML新增名称待核、已对应缺口、前后对照和规则审计四个视图；未匹配名称先留在M0，不当作缺车型交给上游。

维护后在仓库根运行 `python scripts/run_nodes.py --nodes model-year-coverage`。本产线为按需运行，输入变化会提示待刷新。完整原始资料不再放在01；01只保留现有Audi试点所需的38条冻结车型年证据，不依赖本节点。

人工回补清单不包含执行按钮。市场未核时先核市场；00用于建立采集任务，01用于证据核定和补库。采纳与排除须登记依据；不以点击或候选状态代替实际库内结果。
