## 7. 回滚与恢复

- **源码**：两个仓库都没有提交，`git diff` / `git restore` 可按文件回退。本轮改动与上一轮的阶段边界见第 1 节。数据仓库退出跟踪的部分，可用 `git restore --staged <路径>` 恢复跟踪。

- **A0 接口**：网站同时支持新接口和兼容模式；A0 回退到旧版本时自动走兼容模式（打印警告），并记录在批次的 `size_code_map.interface` 中。
