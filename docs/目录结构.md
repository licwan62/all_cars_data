# 项目目录与使用入口

节点登记以根目录 `pipeline.json` 为准。HTML 面向阅读，集中 JSON 面向节点接口，人工规则归各节点 data。

```text
all_cars_data/
├─ 流水线状态.html             全项目入口、依赖关系和状态
├─ pipeline.json              节点、接口、运行和目录契约
├─ nodes/
│  └─ <业务节点>/
│     ├─ <业务名称>.html       当前离线结果、图表、搜索与 CSV 导出
│     ├─ data/                人工规则与资料，优先 CSV
│     ├─ code/ 或 src/        保持登记的代码目录
│     ├─ tests/               业务测试
│     └─ artifacts/<批次>/    不可变 HTML 版本、数据与来源证据
├─ json/
│  ├─ <节点ID>/              当前稳定 JSON 接口
│  │  ├─ manifest.json       数据版本、来源和哈希
│  │  └─ html_manifest.json  页面版本、来源和哈希
│  └─ _meta/                 发布、归档索引及迁移审计
├─ lib/                      共享实现
├─ scripts/                  仓库级正式命令及维护工具
├─ tests/                    仓库级接口与发布测试
├─ docs/                     项目说明
├─ reports/                  验证报告、截图和研究报告
├─ work/                     可重建工作文件及迁移保留文件
├─ cache/                    可重建缓存
└─ portal/data/              持久维护审计与恢复库，必须备份
```

`json/` 集中的是当前机器接口和清单。人工 JSON 配置仍属于 data，历史 JSON 证据仍属于不可变 artifacts；它们不能因整理目录而被修改。根目录 pipeline.json 是项目配置。

人工新增平面规则优先使用 UTF-8 CSV，保留稳定列名和身份字段；嵌套配置可使用 JSON/YAML。修改 data 后按正式入口运行，审核校验结果。不要把生成结果放进 data，也不要手工编辑生成的 JSON 或 HTML。

每个 HTML 使用业务名称，例如 `nodes/A0.尺码计算/尺码计算与匹配.html`。页面完整内嵌当前结果，可直接打开；表格单行完整显示，宽表横向滚动，搜索和 CSV 导出使用同一筛选结果。分类图展示记录行数，避免把多张表的重复记录当成车型总数。

正式生成：`python scripts/run_nodes.py --nodes <节点ID>`。运行器从集中 JSON 读取接口，在独立临时目录物化旧引擎需要的 CSV；计算完成后通过校验和 RunBatch 发布 JSON。不得直接使用旧 engine_run 写正式目录。

仅刷新页面：`python scripts/build_node_html.py`。仅刷新总览：`python scripts/publish_release.py --status-only`。两者都不代表数据重算或新核实。

验证：`python scripts/validate_pipeline_structure.py`、`python scripts/build_node_html.py --check`、`python scripts/verify_pipeline.py`。首次重建可用 `python scripts/verify_pipeline.py --rebuild <节点ID> --fresh`，运行在临时沙箱。

旧节点 output 已退役，未登记的工作结果保留在 `work/legacy-output/<节点ID>/`；搬迁清单和哈希保存在 `json/_meta/layout_changes/`。保留文件应经业务确认后再清理。历史 artifact 不回写；新增版本使用新批次。

NAS 是显式发布的外部 CSV 交换目录，不是节点间接口。本机维护看板的 `portal/data/` 不属于缓存，必须完整持久备份。


## M0车型年覆盖

`nodes/M0.车型年覆盖/` 在02分类审核后形成M线独立分支；原始参考资料由其 `data/data_source/` 维护，当前接口集中在 `json/model-year-coverage/`，阅读入口为节点根目录 `车型年全集与覆盖率.html`。01不依赖M0，原始资料职责迁移不改变尺寸业务结果。M0为原生JSON节点，正式登记命令直接执行src/run.py；不会生成跨节点CSV。
