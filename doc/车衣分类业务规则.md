# 车衣分类业务规则

本文件是 `审核结构字段.md` 的强制业务补充规则。若通用汽车 Body Style 定义与本文件冲突，以本文件的车衣分类口径为准。

## 一、结构字段与分类字段必须分开

- `结构` 描述真实车身形式，例如 Sedan、Hatchback、Liftback、Wagon、SUV、Crossover、Pickup。
- `分类` 描述车衣产品版型，不等同于汽车行业的 Body Style。
- 不得因为 `结构` 使用了更细的行业名称，就在 `分类` 中新增同名类别。

## 二、分类只允许五个值

`分类` 必须且只能使用：

```text
两厢车
跑车
三厢车
越野车
皮卡
```

禁止新增或写入 `旅行车`、`MPV`、`跨界车` 等其他分类值。

## 三、基本映射

| 结构/情况 | 车衣分类 |
|---|---|
| Sedan、Fastback Sedan | 三厢车 |
| Hatchback | 两厢车 |
| Wagon / Estate / Station Wagon | 两厢车 |
| SUV、Crossover、CUV、Coupe SUV | 越野车 |
| Pickup | 皮卡 |
| Coupe、Convertible、Roadster、Targa | 跑车 |

MPV、Van、Minivan 等必须结合实际车身覆盖和现有打版体系，在五类中选择最接近的一类；不得创建第六类。

## 四、Liftback 的车衣分类

`Liftback` 不能固定映射到两厢车，必须联网查看对应 MAKE、MODEL、版本、YEAR 的官方侧面图、后 45 度图或官方技术资料，确认车尾几何：

- **长斜背 Liftback → 三厢车**：车顶至尾部呈较长、连续的轿跑式斜背，后悬/尾部体量接近三厢轿车；即使后窗随尾门开启，车衣版型仍按三厢车。
- **短车尾、高尾门 Liftback → 两厢车**：车尾短、尾门较直或较高、后部体量接近传统 Hatchback，车衣版型按两厢车。

判断记录必须包含直接来源 URL 和简短的形状依据。只看到 `Sportback`、`Fastback`、`Gran Coupé` 营销名称时，不得直接推导分类。

## 五、Suburban 等跨历史车型

- 必须结合 `YEAR`、代际、版本和当年车身资料判断，不能只按 MODEL 名称批量修改。
- “使用 pickup/truck chassis”不等于车身结构就是 Pickup；应检查是否具有独立开放货斗，还是完整封闭乘员/载货车身。
- Chevrolet Suburban 的任何 `Pickup → SUV/Wagon` 建议都必须进入人工复核，禁止自动应用。
- 即使联网证据充分，也只提交建议、适用 YEAR 和来源，由用户手工修改受保护文件。
